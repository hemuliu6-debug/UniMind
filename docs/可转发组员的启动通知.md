# 组员启动通知（可直接复制到小组群）

我们课程黑客松决定做 **UniMind 多学科 AI 学习助手**。10 人共 7 天，一个统一网页，四个学科 Tab：模拟电路、高等数学、大学物理、Python 编程。

本消息附上统一模板 ZIP。请所有人今天完成：

1. 解压 ZIP，确认有 `app.py` 与 `README.md`。
2. 安装 Python 3.13（有多个 Python 版本的同学使用 `py -3.13`）。
3. 双击 `setup_windows.bat` 安装依赖，再双击 `start_windows.bat` 打开网页。
4. 在四个学科 Tab 各输入一个问题，确认能显示“离线演示”回答；没有 API Key 属于正常情况。
5. 阅读 `docs/团队分工与7天计划.md` 和自己的 `docs/学科任务书/`；提交本人的测试截图与交付物。

注意：每组只修改自己学科的 `modules/*.py` 和 `knowledge/*.json`，不得修改公共入口和 API 文件；绝不要在群里公开 API Key，也不要把 `.env` 上传 GitHub。

第一天目标是“每个人都能独立运行”，第三天目标是“四学科模块已经合并进入一个 App”。
