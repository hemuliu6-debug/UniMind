# 学科任务书｜高等数学组（3、4号）

## 目标

让 AI 不只给答案，而是说明定理条件、关键步骤和验算方式，适合大学生看懂推导过程。

## 文件范围

- 3号（代码）：`modules/math_subject.py`
- 4号（知识与测试）：`knowledge/math.json`、自建数学测试题表。

## 必做任务

1. 保留 `answer(question, image=None)` 与 `build_tab()` 两个入口。
2. 提示词要求：适用条件 → 逐步推导 → 最终结果 → 易错点/验算。
3. 维护 3–5 张知识卡（如导数、泰勒公式、积分），写出前提条件。
4. 建立至少 5 道题，包含 1 道条件不足的题和 1 道需要验算的题。
5. 公式应使用 `$...$` 或 `$$...$$`；本组负责检查 LaTeX 格式可读性。

## 验收标准

- 不允许仅给出无步骤答案；不允许把不正确结论当作已证明。
- 若表达式含糊或参数缺失，先指出歧义。
- 不单独部署网页或自己调用 API。

## 可选创新

“只提示下一步”模式、解题步骤复查、自测练习生成。
