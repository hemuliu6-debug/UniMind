# 学科任务书｜大学物理组（5、6号）

## 目标

提供力学、电磁学和基础实验问题的结构化讲解，重点检查单位、正负号和公式的适用条件。

## 文件范围

- 5号（代码）：`modules/physics.py`
- 6号（知识与测试）：`knowledge/physics.json`、自建测试案例表。

## 必做任务

1. 保留 `answer(question, image=None)` 和 `build_tab()`。
2. 提示词要求：已知量 → 物理模型 → 公式条件 → 代入 → 单位与量纲检查。
3. 至少 3 张知识卡（静电场、电磁感应、动力学等）。
4. 至少 5 个测试题，包含单位换算、符号方向、概念辨析和信息不足题。
5. 无法从实验现象确认的判断必须表述为可能性。

## 验收标准

- 实际公式与适用条件正确；输出物理量要写单位。
- 结果能够追溯到输入条件和检索到的知识卡。

## 可选创新

选择“原理讲解/公式求解/实验误差”不同学习模式。
