# 学科任务书｜Python 编程组（7、8号）

## 目标

让用户粘贴 Python 代码或错误提示，生成能理解的报错解释、最小修改示例和验证建议。

## 文件范围

- 7号（代码）：`modules/programming.py`
- 8号（知识与测试）：`knowledge/programming.json`、自建报错测试案例表。

## 必做任务

1. 保留 `answer(question, image=None)` 与 `build_tab()`。
2. 提示词要求：识别异常类型 → 找出可能原因 → 给出最小修复代码 → 教用户如何验证。
3. 至少 3 张知识卡，如 `SyntaxError`、`ModuleNotFoundError`、`IndexError`。
4. 至少 5 条错误案例，包含 1 个提供不完整报错的问题。
5. **只能静态分析代码，不运行用户粘贴的程序**；不能伪称已经运行验证。

## 验收标准

- 代码块格式正确且尽量短小，修改位置明确。
- 不执行、不下载用户提供的未知程序；不显示真实密钥。
- 不能为了诊断报错就要求用户上传环境变量或密码。

## 可选创新

“解释错误/生成测试样例”切换模式、输入错误信息自动分类。
