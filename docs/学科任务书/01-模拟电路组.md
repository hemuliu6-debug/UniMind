# 学科任务书｜模拟电路组（1、2号）

## 目标

让大学生上传 Multisim 等电路仿真截图或输入故障现象，收到有依据、可执行的排查建议。你们负责独立的模电模块，**不负责整个网站**。

## 文件范围

- 1号（代码）：`modules/circuit.py`
- 2号（知识与测试）：`knowledge/circuit.json`、自建模电测试案例表
- 不得直接修改 `app.py`、`core/` 或 `.env` 的共享版本。

## 必做任务

1. 保留 `answer(question, image=None)` 和 `build_tab()`。
2. 优化 Prompt，使回答结构为“已确认信息 → 可能原因 → 按顺序检查 → 需要用户补充的信息”。
3. 至少 3 张有明确适用条件的知识卡（示波器无波形、RL 电路、交流有效值等）。
4. 至少 5 个测试案例，含 **1 个无法确定原因** 的案例。
5. 图片分析时不得凭模糊截图猜元件值或断言电路故障；涉及高电压时避免实操风险指令。

## 验收标准

- 在模拟电路 Tab 能完成文字提问；9号在线验证图片提问。
- 正常输入和空输入均有友好反馈；知识卡能按关键词命中。
- 不添加新端口、不私自新建 API Key 配置、不修改其他组文件。

## 可选创新

故障类型选择下拉框、逐步排查流程、回答中的图像观察与推断分离。
